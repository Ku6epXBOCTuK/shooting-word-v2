# Визуальные эффекты (vfx)

Как устроен слой эффектов. Правила для нового эффекта — в AGENTS.md: реестр
`src/lib/vfx/registry.ts`, время от хоста в `VfxFrame`, размеры долями
`state.radius`.

## Слои

| Слой      | Где             | Отвечает за  |
| --------- | --------------- | ------------ |
| ECS       | `game/types.ts` | когда и где  |
| Рисование | `src/lib/vfx/*` | как выглядит |
| Слой      | `vfx/layer.ts`  | обслуживание |

Время приходит от хоста: в игре — накопленный `dt`, на `/view` — дельта тикера.
Внутри эффектов нет ни `performance.now()`, ни чтения ECS.

## Файлы

| Файл           | Содержимое                                                                        |
| -------------- | --------------------------------------------------------------------------------- |
| `kinds.ts`     | виды эффектов, без Pixi                                                           |
| `durations.ts` | сроки жизни откликов и `shieldHit()`, без Pixi — их читает логика headless-сборки |
| `types.ts`     | контракты: `VfxFrame`, `VfxReaction`, `VfxStateful`, `VfxFilter`, `AuraStates`    |
| `layer.ts`     | слой: общее время, крепление, снос                                                |
| `registry.ts`  | вид эффекта → фабрика                                                             |
| `reactions.ts` | одноразовые отклики                                                               |
| `auras.ts`     | долгоживущие: щит, перегрузка, doomsday, портал                                   |
| `shield.ts`    | шейдер щита                                                                       |
| `shimmer.ts`   | шейдер покрытия                                                                   |

## Виды

Отклик (`REACTION_KINDS`, компонент `vfx`) — живёт доли секунды: `ship-hit`,
`ship-ricochet`, `word-destroyed`, `bullet-miss`, `viewer-destroyed`,
`word-kill-mark`, `device-spark`, `doomsday`, `timestop`, `reward`.

Аура (`AURA_KINDS`) — пока активна, рисуется контейнером: `shield`,
`overcharge`, `doomsday`, `portal`.

Покрытие (`COATING_KINDS`) — фильтр на чужом спрайте: `armorCoating`.

Создать отклик — одна строка `addReaction(ctx, at, kind, value)` из
`game/reaction.ts`. Систем всего две на все отклики: `systems/vfx.ts` старит,
`systems/vfx-render.ts` рисует.

## Награда и визуал

`RewardConfig.visual` — обязательное поле: награда без визуала не собирается.
Варианты: аура, покрытие, только вспышка; у всех есть `reaction` и `color`.
`core.ts` спавнит отклик только в ветке «компонента ещё не было», поэтому
повторное продление той же награды реакции не даёт.

## Щит

Шейдерная оболочка: волны по кругу и по радиусу, шум, ободок. Искажение от
попадания расходится из точки удара (`Shield.hitAt` / `Shield.hitFrom`),
затухание считает хост — аура часов не знает.

Форму задаёт текстура-круг, а не координаты шейдера: альфа линейно падает от
центра к краю, поэтому радиус берётся как `1 - alpha`. Это не зависит от того,
как Pixi считает UV для фильтра.

Все размеры — доли `state.radius`, поэтому щит одинаково читается при любом
`viewerScale`.
