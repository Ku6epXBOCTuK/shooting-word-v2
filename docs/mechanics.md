# Механики игры

Гайд для игроков.

## Корабль

Твой корабль появляется внизу экрана. Двигается сам, управлять им нельзя. Если
не писать в чат, корабль улетает

## Стрельба

Напиши в чат слово с экрана, корабль выстрелит по врагу с этим словом.

- Сообщение должно целиком совпадать со словом, регистр не важен.
- Если такого слова на экране нет, сообщение ничего не делает.
- Разрушенный корабль не стреляет.

За уничтоженного врага игра даёт +1 опыт.

## Враги

Слова прилетают и зависают на экране. Если за отведённое время слово не сбить,
оно стреляет по случайному кораблю и исчезает.

## Вражеский выстрел

Попадает не каждый снаряд. При промахе снаряд рикошетит: урона нет, заряд щита
не тратится. Попадание снимает прочность.

## Прочность и разрушение

Прочность корабля конечна и со временем не восстанавливается — только батареями.
Когда прочность кончается, корабль разрушается.

Возврат после разрушения:

- обычный режим: через время, в случайном месте;
- раунд: разрушение до конца раунда, вернуться раньше можно только аварийным
  маяком;
- когда разрушены все корабли, раунд заканчивается.

### Силовой щит

Работает ограниченное время. У щита несколько зарядов: каждое вражеское
попадание тратит заряд вместо прочности. Промахи заряд не тратят. Заряды
восстанавливаются со временем до предела. Повторная покупка при активном щите не
срабатывает.

### Батарея

Жетон ремонта, хранится между сессиями, лимит жетонов есть. `!repair`:
восстанавливает немного прочности себе. `!repair @ник`: тратит твою батарею на
другого игрока, ему достаётся больше прочности. Разрушенный корабль и корабль с
полной прочностью чинить нельзя.

### Аварийный маяк

Жетон возврата, максимум 1 штука. Расходуется сам при разрушении корабля в
раунде: корабль вскоре возвращается на то же место с полной прочностью. В
обычном режиме не тратится, там возврат бесплатный.

### Циномаяк

Жетон возврата другого игрока, максимум 1 штука. Потратить: `!маяк @ник` во
время раунда. Вскоре разрушенный корабль возвращается на то же место с полной
прочностью. Если ник не найден или корабль целый, жетон не тратится.

### Doomsday device

Пока устройство активно, все слова на экране замораживаются, новые слова во
время активации тоже. Из центра по замороженным словам летят снаряды и взрывают
их. Нельзя активировать, если кто-то уже активировал устройство.

### Перегрузка

Действует ограниченное время. Пока активна, корабль стреляет по каждому слову из
твоего сообщения, а не только по первому. Повторная покупка при активной
перегрузке не срабатывает.

### Рикошетиум

Действует ограниченное время. Снаряды врагов реже наносят урон твоему кораблю.
Повторная покупка при активной обмазке не срабатывает.

## Команды игрока

| Команда        | Действие                                       |
| -------------- | ---------------------------------------------- |
| `<слово>`      | выстрел по врагу с таким словом                |
| `!скин`        | случайный корабль                              |
| `!скин 7`      | корабль номер 7 (всего 20)                     |
| `!repair`      | потратить батарею, восстановить себе прочность |
| `!repair @ник` | потратить батарею, восстановить другому        |
| `!маяк @ник`   | потратить циномаяк, вернуть игрока             |
