# Balance simulation

Сгенерировано: `CALIBRATE=1 npx vitest run src/lib/game/balance/sim.spec.ts`

Цели: `docs/balance-targets.md`. Активный режим (!игра): смерть перманентна,
конец раунда = вайп всех. Цель: вайп за 2–3 мин без баффов, 8–12 мин с баффами
60% времени (щит uptime 0.6 + 12 батареи/час, ремонт +5 hp).

Модель: headless-прогон реальных ECS-систем (`src/lib/game/balance/sim.ts` на
`createHeadlessGame`), без отдельного движка. Реальные константы: спавн 2–4 сек,
кап MAX_ENEMIES 30, фьюз вооружённого слова 1000 мс, урон 1 hp с шансом `p`
(сетка), батарея +3 hp, щит 3 hp (реген 1 / 20 сек), печать 3.5 зн/сек + реакция
3 сек (включает стрим-задержку), ttl слова 12 сек, активных 50%, прогонов на
ячейку: 10.

**Жирным** — попадание в целевое окно (без баффов 2–3 мин, с баффами 8–12 мин);
«≥30.0» = не все прогоны завершились вайпом.
