# VFX: единый слой эффектов

Задачи из [backlog.md](../backlog.md) выполнены: «отрефакторить эффекты»,
«визуал для эффектов», «отрефакторить щит». Документ — что получилось, без
истории разработки.

## Слои

| Слой      | Где             | Отвечает за  |
| --------- | --------------- | ------------ |
| ECS       | `game/types.ts` | когда и где  |
| Рисование | `src/lib/vfx/*` | как выглядит |
| Слой      | `vfx/layer.ts`  | обслуживание |

Время приходит от хоста: в игре — накопленный `dt`, на `/view` — дельта тикера.
Внутри эффектов нет ни `performance.now()`, ни чтения ECS.

## Файлы `src/lib/vfx/`

| Файл           | Содержимое                                                                           |
| -------------- | ------------------------------------------------------------------------------------ |
| `kinds.ts`     | виды эффектов, без Pixi                                                              |
| `durations.ts` | сроки жизни откликов и `shieldHit()`, без Pixi                                       |
| `types.ts`     | контракты: `VfxFrame`, `VfxReaction`, `VfxStateful`, `VfxFilter`, карта `AuraStates` |
| `layer.ts`     | слой: общее время, крепление, снос                                                   |
| `registry.ts`  | вид эффекта → фабрика                                                                |
| `reactions.ts` | одноразовые отклики                                                                  |
| `auras.ts`     | долгоживущие эффекты: щит, перегрузка, doomsday, портал                              |
| `shield.ts`    | шейдер щита                                                                          |
| `shimmer.ts`   | шейдер обмазки рикошетиумом                                                          |

## Виды

Отклик (`REACTION_KINDS`) — живёт доли секунды, компонент `vfx`:

`ship-hit`, `ship-ricochet`, `word-destroyed`, `bullet-miss`,
`viewer-destroyed`, `word-kill-mark`, `device-spark`, `doomsday`, `timestop`,
`reward`

Аура (`AURA_KINDS`) — пока активно, рисуется контейнером:

`shield`, `overcharge`, `doomsday`, `portal`

Покрытие (`COATING_KINDS`) — фильтр на чужом спрайте:

`ricochetium`

## Системы

Всего две на все отклики: `systems/vfx.ts` старит сущности,
`systems/vfx-render.ts` рисует. Создать отклик — одна строка через
`addReaction(ctx, at, kind, value)` из `game/reaction.ts`.

Бывшие `spark`, `ricochet`, `star`, `explosion` — восемь файлов систем, четыре
компонента. Сроки лежат в `vfx/durations.ts`, потому что их читает логика, а в
headless-сборке рендер-систем нет вовсе.

## Визуал награды

`RewardConfig.visual` — обязательное поле, награда без визуала не собирается.
Три варианта: аура, покрытие, только вспышка. У всех есть `reaction` и `color`.

`core.ts` спавнит отклик в ветке «компонента ещё не было», поэтому повторное
продление того же щита реакцию не даёт.

## Щит

Шейдерная оболочка: волны по кругу и по радиусу, шум, ободок. При попадании
`Shield.hitAt` и `Shield.hitFrom` дают искажение, расходящееся от точки удара.
Затухание считает хост, аура часов не знает.

Форму щита задаёт текстура-круг, а не координаты шейдера: альфа линейно падает
от центра к краю, поэтому радиус берётся как `1 - alpha`. Это не зависит от
того, как Pixi считает UV для фильтра.

Все размеры — доли `state.radius`, поэтому щит одинаково читается при любом
`viewerScale`.
