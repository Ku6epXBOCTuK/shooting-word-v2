# Управление игрой: стример и модераторы

Механики, которыми управляют стример и модераторы. Гайд для игроков:
[mechanics.md](./mechanics.md).

## Режимы игры

| Режим   | Как включается         | Что происходит                                                                                                 |
| ------- | ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| Обычный | по умолчанию           | Спокойный спавн слов (2-4 сек), разрушение не страшно: автовозврат через 30 сек                                |
| Раунд   | `!игра` (мод)          | Отсчёт 9 сек, потом раунд до разрушения всех кораблей. Баннер «игра завершена» 10 сек, возврат в обычный режим |
| AFK     | `!афк` / `!афк-` (мод) | Раунды перезапускаются сами через 30 сек после конца игры                                                      |

Запустить раунд можно только из обычного режима.

## Давление в раунде

Враги спавнятся тем чаще, чем больше кораблей в строю.

## Жизненный цикл слова

Слова прилетают и зависают на экране. Каждое висит 30 секунд. Если за это время
слово не сбить, оно стреляет по случайному кораблю и исчезает.

## Настройки

Страница конфигурации: кабинет в полной версии, `/settings` в статике.

| Параметр            | По умолчанию | Что меняет                                |
| ------------------- | ------------ | ----------------------------------------- |
| Масштаб кораблей    | 2            | размер кораблей зрителей (0.5-6)          |
| автосписание баллов | выкл         | помечать выданные награды выполненными    |
| авто-возврат баллов | вкл          | возврат баллов при активации сверх лимита |

Масштаб кораблей доступен и в статике, остальное только в полной версии.
Название, стоимость и кулдаун каждой награды настраиваются отдельно (тоже только
в полной версии). Значения по умолчанию: щит 300, батарея 200, маяк 400,
doomsday device 2000.

Параметры баланса (базовое hp, шанс урона врага, давление спавна, время жизни
слова, лечение и лимит батарей, время возврата) меняются только в коде и в
dev-режиме.

## Команды модераторов

| Команда     | Действие                                       |
| ----------- | ---------------------------------------------- |
| `!игра`     | запустить раунд                                |
| `!афк`      | включить afk-режим (автоперезапуск раундов)    |
| `!афк-`     | выключить afk-режим                            |
| `!боты [N]` | добавить N ботов (по умолчанию 5, максимум 20) |
| `!боты-`    | убрать всех ботов                              |

## Заметки

- Зритель появляется после первого сообщения в чате; любая активация награды
  тоже вызывает корабль.
- Игра убирает с экрана зрителя, который молчал 12 часов; прогресс сохраняется.
- Опыт, батареи, маяки и щиты сохраняются между сессиями (sqlite в полной
  версии, localStorage в статике).
- В раунде разрушение перманентно до конца раунда; аварийный маяк срабатывает
  автоматически.
- Баланс и целевые окна по длительности раунда: [balance.md](./balance.md) и
  [balance-targets.md](./balance-targets.md).
