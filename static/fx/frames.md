# Нумерация кадров fx

Кадры спрайт-листов называем меткой вида `b3`.

## Схема

- ряд = буква: `a` - верхний, далее сверху вниз
- колонка = число: `1` - левая, далее слева направо
- отсчёт от левого верхнего угла листа

Примеры: `a1` - левый верхний кадр, `b3` - второй ряд, третья колонка, `m36` -
нижний правый кадр.

## Расшифровка метки в пиксели

Метка `<ряд><колонка>`, например `b3`:

- row = 2 (b - вторая буква), col = 3
- x = (col - 1) \* 16 = 32
- y = (row - 1) \* 16 = 16
- rect = [32, 16, 16, 16]

## Файлы с сеткой

`<name>.grid.svg` рядом с каждым листом - та же картинка с наложенной сеткой и
подписями меток. Генерируются скриптом `scripts/fx-grid.mjs`, при смене листа
перегенерировать.
